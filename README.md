# Genetix

Genetix is a mobile ecosystem/evolution simulation game in which the world lives on its own and the player influences conditions rather than directly controlling outcomes.

## Project status

**Phase:** Pre-production / Project Foundation v0.1  
**Current objective:** Define the smallest autonomous simulation that can produce interesting ecological histories before choosing implementation details that are difficult to reverse.

## Core product rule

> The player creates conditions. Life creates the result.

## Current non-goals

- No engine choice yet.
- No production art pipeline yet.
- No detailed genetics model yet.
- No civilization layer.
- No premature multithreading.
- No implementation whose only justification is speculative future complexity.

These may be added later when justified by validated gameplay or measured technical need.
